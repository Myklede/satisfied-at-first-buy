## Collar moment

Ask the judge to enter their own inputs voluntarily, choose puffer S, and close the zip before discussing collar ease. Read the actual returned label and note. The sweep often found tight/snug S collars in male grid cases, but smaller female cases can be roomy; there is no universal weight threshold. Never promise or force red. If the result is regular/roomy, explain that result and compare the real jacket honestly.

S collar-inner tape minus estimated neck section gives ease. Tight/snug boundaries are provisional comfort language; the neck estimate is section-dependent, with HIGH non-monotonic height examples in the [sweep](look/collar-sweep.md). M/L collar measurements are missing, so changing size does not demonstrate collar relief. Do not treat an unknown collar as comfortable.
